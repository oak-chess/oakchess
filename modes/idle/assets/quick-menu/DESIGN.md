# Atalhos laterais ilustrados

`approved-concept.png` é a proposta visual aprovada pelo usuário. `buttons-atlas.png` é a preparação transparente dos quatro botões para uso no jogo, feita com a ferramenta integrada de imagens.

Os botões nativos e seus rótulos acessíveis foram preservados. O CSS enquadra cada linha do atlas, sem editar pixels. O ícone permanece alinhado à direita; o nome é revelado aumentando a largura para a esquerda. Mouse e foco visível de teclado expandem o botão; preferência de movimento reduzido desativa a transição. Falha de carregamento mantém os controles anteriores visíveis.

Prompt da preparação:

Preserve each of the four button artworks, exact icons, Portuguese labels, dark metal, red trim and cyan small indicator lights. Preserve their current size, arrangement and position on the canvas. Remove the forest backdrop entirely to real transparency. Remove the large vertical mounting rail on the far right, leaving four individual COMPLETE horizontal button outlines with transparent gaps between them; finish the tiny cut-off right edge of each bezel naturally in the same metal style. Remove ONLY the bright cyan outline glow around the top Loja button so all four buttons have the same neutral unselected red/dark metallic frame. Keep the shop icon, automation gear/capsule, report tablet and gold reward chest exactly as drawn. Exact labels Loja, Automação, Registro, Recompensas. No redesign, no new symbols, no extra copies, no additional words. This will be used as the actual artwork of hover-expanding UI controls. Transparent background.
