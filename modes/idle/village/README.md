# Vila das Margens

Integrated into Jornada Idle. Progress belongs to the existing journey save, not to the visual prototypes. The native runtime validates wallet changes, deeds, house reservations, catches, sales and PC transfers before acknowledging the service frames.

Art: village-v1.webp and village-wide-v2.webp were created with the built-in image generator for OakChess. Pokémon and NPC sprites reuse the existing credited project assets. Fishing backgrounds reuse modes/idle/assets/safari-art. Activity sounds are original procedural synthesis; background music uses the existing Idle garden track.

Rules: up to four installed houses. Deeds cost 5,000 gold or 10 Deed Fragments each; repeated deeds remain owned. House XP rates are 25%, 40%, 75%, 100% and 100% per resident. Only Legendary houses have two slots; other houses have one. The combat team keeps all its XP. Materials from recycling fund cosmetics. Legacy training upgrade materials are refunded, Epic houses become Mythical, and extra residents return safely to the native PC. Fishing catches use the native individual generator and shared shiny guarantee. The bucket holds 300 catches; completed orders and rod quests persist.

Common hunt victories have a 0.5% fragment chance. Each first route boss grants two. Rosa rewards five for 100 wins each week, resetting Mondays at 00:00 Brasilia time. Fusion consumes five explicitly selected, unlocked stored Common deeds for Uncommon, or five Uncommon for Rare. See HOUSE-PLAN.md.

Validation: scripts/check-house-fragments.cjs, scripts/check-house-fragments-browser.cjs, scripts/check-house-share-table.cjs, scripts/check-village-service.cjs and scripts/check-village-live.cjs.
