# Protótipo de menu retrô

Usa a tela inicial e as funções do jogo com uma janela de menu em coluna. Duas aparências: GBA clássico e Game Boy monocromático. Dados salvos em namespace exclusivo, sem alterar a coleção ou partidas do jogo principal.

Gerar: node prototypes/retro-menu/build.cjs

## Biblioteca de jogos
Nova direção visual de streaming: destaque com arena em movimento, biblioteca de Campanha e Torre e atalhos para as funções reais. As duas opções são modos existentes do OakChess, sem inventar títulos adicionais. Apenas protótipo.

## Arte da logo
Logo ilustrada gerada para o projeto com fundo transparente em pokemon-oakchess-logo-v1.png. Substitui o texto CSS apenas neste protótipo. Personagens e marca Pokémon pertencem aos respectivos titulares.
