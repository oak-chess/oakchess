# Sprites dos itens do protótipo idle

Poção, Revive, Pedra do Gelo, Cogumelo Pequeno, Poeira Estelar e Pérola: sprites Pokémon distribuídos pelo repositório [PokeAPI/sprites](https://github.com/PokeAPI/sprites/tree/master/sprites/items), adicionados localmente para funcionamento offline.

Poção e Revive substituem os ícones SVG utilizados anteriormente no protótipo. Os nomes do loot foram ajustados aos itens representados pelos sprites; os identificadores do save e as quantidades permanecem iguais. Preços e efeitos são regras do protótipo.
